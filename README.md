# Monora-translation

## Cómo compartir correcciones de traducción

La forma más clara de proponer una corrección es abrir un *issue* en este repositorio. Actualmente no hay archivos de traducción aquí para editar directamente; un *issue* permite localizar cada texto y acordar dónde incorporar el cambio.

Para que la corrección se pueda revisar, incluye:

- El idioma y la pantalla donde aparece el texto.
- El texto actual y la traducción propuesta, copiados tal cual.
- El contexto de la pantalla y el motivo de la corrección (por ejemplo, un error, una frase poco natural o una inconsistencia).
- El enlace a la página y, si ayuda, una captura de pantalla. Oculta cualquier dato personal o sensible.

Puedes usar este formato:

```text
Idioma:
Pantalla o sección:
Texto actual:
Corrección propuesta:
Motivo/contexto:
Enlace o captura (opcional):
```

Para el panel de ejemplo, indica que el texto aparece en [Reporting > Dashboard](https://monora.mypi.net/reporting/dashboard/monosite?siteId=45717).

Si más adelante se añaden archivos de traducción a este repositorio, también se podrán proponer cambios mediante un *pull request*, conservando las claves y los marcadores del texto original.
